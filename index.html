DB 파일을 놓거나 선택

Python판이 만든 wordchain.sqlite3를 권장합니다. TXT·CSV·JSON 단어 목록도 지원합니다.

파일은 이 컴퓨터의 브라우저 안에서만 처리됩니다.

SQLite 파일은 외부 엔진·인터넷 없이 HTML 내부 파서가 entries.normalized_word 열을 읽습니다. 약 200MB DB는 처리에 수십 초가 걸릴 수 있습니다.
